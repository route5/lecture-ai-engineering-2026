# 第1回 解答

## 演習

- 使用モデル：`gemini-3.5-flash-lite`（モデルは固定）
- 実行方法：各質問をtemperature 0.3 / 0.5 / 1.5で1回ずつ、合計9回実行
- 質問：「LoRA とは何ですか？」
  - 0.3：低ランク適応の略で、基盤モデルを固定し小さな追加部分を学習すると説明。辞書と付箋のたとえを使い、画像生成やLLMでの利用にも触れた。
  - 0.5：同じ仕組みを「補助頭脳」と説明し、メモリ・学習時間・保存サイズの利点や用途をより詳しく列挙した。
  - 1.5：同じ要点を保ちつつ、「知識のノート」「プラグイン」のたとえで説明。低コストで手元のPCでも使えるという表現が強くなった。
- 質問：「AIE2026 の講座の宿題にある『3レベル』とは何ですか？」
  - 0.3：講座固有の情報は知らないと断った後、一般的な初級・中級・上級の課題だと推測した。
  - 0.5：難易度の3段階に加え、AI活用スキルの3段階という別の可能性も提示した。
  - 1.5：「AI Engineer 2026」などの略称まで推測し、基礎・応用・発展の一般論を詳しく説明した。
- 質問：「AIE2026の第2回では何を学びますか？」
  - 0.3 / 0.5 / 1.5：いずれも講座の詳細を知らないと答え、主催者や分野などの追加情報を求めた。temperatureを変えても回答の結論はほぼ同じだった。
- 用語集・講座資料との比較：
  - 宿題の3レベルは一般的な初級・中級・上級ではなく、「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」。どれか1つに取り組めば宿題は完了する。モデルは講座固有の事実を知らず、もっともらしい一般論を生成した。
  - 第2回はLoRAで回答形式を学習し、学習前後を比較する演習。形式遵守と内容正解を別々に評価し、学習によって何が変わり何が変わらないかを確かめる。3回ともこの情報は答えられなかった。
  - LoRAの中心的な説明は共通していた。より正確には、事前学習済みの重みを固定し、重みの更新分を2つの小さな低ランク行列の積で表して、その行列だけを学習する手法。回答中のパラメータ割合やファイルサイズなどの具体的な数値は回答ごとに揺れ、一般化できる値としては確認が必要。
- 気づき：temperatureを上げると説明のたとえや詳しさ、講座固有情報についての推測が増えた。一方、temperatureだけではモデルが持たない講座情報は補えず、低温でも誤った一般論を断定することがある。根拠となる資料や検索ツールを使って確認する必要がある。

## 宿題

- 取り組んだレベル：基礎
- やったこと：3つの質問 `gemini-3.5-flash-lite` および上位モデル`gemini-3.8-flash`に送り、temperatureを0.3、0.5、1.5に変えて各1回、合計9回実行した。
- 結果：`gemini-3.5-flash-lite` では、LoRAの一般的な説明は概ね共通したが、説明の長さやたとえ、数値の具体例は変化した。講座固有の2問は、temperatureを変えても正しい講座情報を回答できなかった。また、上位モデル`gemini-3.8-flash`は、503（モデルの高需要）で失敗し、保存できた回答得られなかった。
- 気づき・疑問：temperatureは回答の多様さに影響するが、事実の正しさを保証しない。講座固有の質問には、用語集や講義資料を検索して回答の根拠を与える方法が有効。
